# Security policy

## Supported versions

Only the latest release and `main` receive fixes while the project is pre-1.0.

## Reporting a vulnerability

Please **do not** open a public issue. Report privately through GitHub:
[Report a vulnerability](https://github.com/aniketpratapsingh/alphashape/security/advisories/new).

Include the affected version, the input file or steps that trigger the problem, and the impact you
see. Project files, images and raster/point-cloud imports are the main untrusted inputs. Expect a
first reply within 7 days.

Fixed vulnerabilities are published as GitHub security advisories and called out in the release notes
of the version that contains the fix. Reports are acknowledged within 7 days and a fix or mitigation
plan is normally given within 60 days. There are no known unpatched vulnerabilities of medium or
higher severity that are older than 60 days.
